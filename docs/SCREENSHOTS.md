# Screenshots for your report

A suggested set of screenshots that show the breadth of the project. For
each, a sentence on what it demonstrates.

1. **Home** (`/home`) -- the hero, "how it works" steps, and live impact
   strip. Shows the custom design system and that real data is flowing
   from the dashboard into the homepage.
2. **Scan an item** (`/upload`) -- a result card showing a predicted
   category and confidence bar. Take one with the file-upload path and,
   if your laptop has a camera, one using the "Use camera" capture flow.
3. **My scans** (`/my-scans`) -- the thumbnail history. Shows the
   DynamoDB-backed scan log working end to end.
4. **Where does it go?** (`/where-does-it-go`) -- the search page with a
   query typed in and filtered results showing. Demonstrates the
   124-item database.
5. **Dashboard** (`/dashboard`) -- the stacked trend chart, streak,
   weekly goal progress bar, challenges, and badge shelf together.
6. **Segregation game** (`/segregation-game`) -- mid-game, with the
   timer and score visible.
7. **Waste audit results** (`/waste-audit`) -- the score and top-3
   improvements screen, after submitting the quiz.
8. **Nearby centres** (`/nearby-centres`) -- the category cards, ideally
   with a location typed in.
9. **Ask Haraa / chatbot** (`/chat`) -- a conversation, with the "Chat
   status" indicator visible at the bottom showing which provider
   answered.
10. **Model Performance** (`/model-performance`) -- the confusion matrix
    and per-class precision/recall/F1 table. This is one of only two
    pages (plus About) where the underlying tech stack is named, which
    is worth mentioning in your report.
11. **About** (`/about`) -- the architecture diagram and cost summary.
12. **Collection reminders** (`/collection-reminders`) -- the weekday
    picker and, if set, the "collection is today/tomorrow" banner.
13. **Poster** (`/poster`) -- the printable A4 layout (a browser print
    preview screenshot works well here).
14. **Dark mode** -- toggle it on any page (the home page or dashboard
    work well) to show the theme isn't just an inverted default.
15. **Tamil language view** -- switch the language selector in the
    navbar and screenshot the home page or "Where does it go?" page, to
    show the i18n feature working. Worth pairing with a one-line caption
    noting which parts are translated (see the README's "What doesn't
    work" section for the exact scope).
16. **Mobile/responsive view** -- resize your browser or use dev tools'
    device toolbar on the home page, to show the responsive layout.
